## 3. 实验原理

### 3.1 卷积运算基础

卷积是图像处理中的基本操作，其数学表达式为：

```
(f * g)(x, y) = ∑∑ f(m, n) × g(x-m, y-n)
```

在数字图像处理中，卷积通常用于：
- 边缘检测
- 图像滤波
- 特征提取
- 图像增强

### 3.2 模板分析

指定模板：
```
[[-1,  0,  1],
 [-2,  0,  2],
 [-1,  0,  1]]
```

**模板特性分析**：

1. **模板类型**: Sobel垂直边缘检测算子
2. **结构特点**:
   - 左列系数为负值 (-1, -2, -1)
   - 中列系数为零 (0, 0, 0)
   - 右列系数为正值 (1, 2, 1)

3. **作用机制**:
   - 检测图像中垂直方向的边缘
   - 计算水平方向的梯度（亮度变化率）
   - 对从左到右的亮度变化敏感

4. **响应特性**:
   - 左暗右亮区域：产生正响应（白色）
   - 左亮右暗区域：产生负响应（黑色）
   - 均匀区域：响应接近零（灰色）

## 4. 实验实现

### 4.1 核心算法

#### 手动卷积实现
```python
def manual_convolution(self, image, kernel):
    # 获取尺寸
    img_height, img_width = image.shape
    kernel_height, kernel_width = kernel.shape
    
    # 零填充
    pad_h = kernel_height // 2
    pad_w = kernel_width // 2
    padded_image = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), 
                         mode='constant', constant_values=0)
    
    # 卷积运算
    output = np.zeros((img_height, img_width), dtype=np.float32)
    for i in range(img_height):
        for j in range(img_width):
            window = padded_image[i:i+kernel_height, j:j+kernel_width]
            output[i, j] = np.sum(window * kernel)
    
    return output
```

#### OpenCV卷积实现
```python
def opencv_convolution(self, image, kernel):
    result = cv2.filter2D(image, cv2.CV_32F, kernel)
    return result
```

### 4.2 结果处理

由于卷积结果可能包含负值和超出0-255范围的值，需要进行归一化处理：

```python
def normalize_result(self, result):
    min_val = np.min(result)
    max_val = np.max(result)
    
    if max_val - min_val != 0:
        normalized = ((result - min_val) / (max_val - min_val) * 255).astype(np.uint8)
    else:
        normalized = np.zeros_like(result, dtype=np.uint8)
        
    return normalized
```

## 6. 模板作用总结

### 6.1 主要功能
- **边缘检测**: 专门检测垂直方向的边缘
- **梯度计算**: 计算水平方向的一阶导数
- **特征提取**: 提取图像中的垂直结构特征

### 6.2 应用场景
- 计算机视觉中的预处理
- 目标检测中的特征提取
- 图像分析中的边缘定位
- 模式识别中的特征描述

### 6.3 优缺点分析

**优点**:
- 对垂直边缘检测效果好
- 计算简单，效率高
- 对噪声有一定的抑制作用

**缺点**:
- 只能检测垂直方向的边缘
- 对斜向边缘检测效果差
- 需要与水平Sobel算子配合使用才能检测所有方向的边缘

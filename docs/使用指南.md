## 详细功能说明

### 核心模板分析

使用的模板：
```
[[-1,  0,  1],
 [-2,  0,  2],
 [-1,  0,  1]]
```

**这是什么？**
- 名称：Sobel垂直边缘检测算子
- 作用：检测图像中垂直方向的边缘
- 原理：计算水平方向的梯度（亮度变化率）

**如何工作？**
1. 左列系数为负值(-1, -2, -1)：对左侧像素赋予负权重
2. 中列系数为零(0, 0, 0)：忽略中间像素
3. 右列系数为正值(1, 2, 1)：对右侧像素赋予正权重

**检测效果：**
- ✅ 垂直边缘：强烈响应
- ❌ 水平边缘：响应很弱
- ❌ 均匀区域：几乎无响应

### 卷积运算过程

1. **输入**：灰度图像 + 3×3模板
2. **处理**：
   - 将模板在图像上滑动
   - 每个位置计算模板与图像窗口的乘积和
   - 结果作为输出图像的像素值
3. **输出**：边缘检测结果图像

### 结果解读

**数值含义：**
- 正值（白色）：从左暗到右亮的边缘
- 负值（黑色）：从左亮到右暗的边缘  
- 零值（灰色）：无明显边缘变化

**典型结果：**
- 矩形左边缘：负值（黑色）
- 矩形右边缘：正值（白色）
- 圆形左弧：负值（黑色）
- 圆形右弧：正值（白色）

## 常见问题解答

### Q1: 为什么卷积结果有负值？
**A**: 这是正常现象。负值表示从亮到暗的边缘，正值表示从暗到亮的边缘。

### Q2: 归一化的目的是什么？
**A**: 卷积结果可能超出0-255范围，归一化将其映射到标准灰度范围，便于显示。

### Q3: 为什么只检测垂直边缘？
**A**: 因为使用的是垂直Sobel算子。要检测所有方向的边缘，需要结合水平算子。

### Q4: 如何提高边缘检测效果？
**A**: 可以：
- 预先对图像进行高斯滤波降噪
- 结合多个方向的算子
- 使用Canny边缘检测算法

### Q5: 手动卷积和OpenCV卷积有什么区别？
**A**: 
- 算法原理相同
- OpenCV实现经过高度优化，速度更快
- 手动实现便于理解原理，适合学习
